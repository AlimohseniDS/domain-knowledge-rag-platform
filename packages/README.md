# Shared packages

Provider-neutral business modules used by the deployable applications.

- `ingestion`: parsing and chunk construction
- `storage`: filesystem and S3-compatible document storage
- `retrieval`: vector, keyword, fusion, and reranking logic
- `generation`: grounded prompt and answer orchestration
- `providers`: LLM, embedding, and reranker adapters
- `permissions`: authorization policies and filters
- `evaluation`: versioned RAG quality evaluation
